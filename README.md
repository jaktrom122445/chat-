# Musikverein Unterentersbach – Website

Responsive statische Website mit semantischem HTML, CSS und Vanilla JavaScript; kein Framework und kein Build-Schritt erforderlich.

## Lokal starten
`python3 -m http.server 8000` und anschließend `http://localhost:8000` öffnen.

## Vor dem Livegang
- Original-Vereinsfotos mit geklärten Bildrechten ergänzen.
- Termine und Nachrichten nur aus bestätigten Vereinsquellen übernehmen.
- Vorstand, Vereinsregister und Impressum anhand aktueller Unterlagen bestätigen.
- Datenschutzerklärung anhand Hosting und tatsächlich verwendeter Dienste rechtlich vervollständigen.
- Lokale Schriftdateien statt externer Schriftanbieter einsetzen und Datenschutz prüfen.
- Browser-, Tastatur-, Screenreader- und Mobiltests durchführen.

Es wurden keine Zugangsdaten, Secrets oder Deployment-Einstellungen verändert.
